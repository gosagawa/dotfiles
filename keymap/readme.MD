
# 導入手順

1. https://github.com/omkbd/ErgoDash/をクローン
2. Firmware/ErgoDash_rev1_via/ergodash_rev1_via.hexをQMK Toolboxで書き込む
3. Firmware/ErgoDash_rev1_via/ErgoDash.jsonをVIAで読み込む
4. このフォルダのErgoDash.jsonをロードする
